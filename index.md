## 🛠️ Troubleshooting Common Issues

### My download seems slow or stuck
- Check your internet connection. Are other devices or apps using bandwidth?
- Try reducing the number of connections in settings (8 or 4 instead of 16).
- The server might limit connections. Try pausing and resuming the download.

### plexo won't open after installation
- Make sure your operating system is up to date.
- Try running the application as administrator (right-click, "Run as administrator" on Windows).
- Reinstall plexo after restarting your computer.

### I can't find my downloaded files
- Check the default download folder (usually "Downloads" on your computer).
- If you changed the location during setup, go to plexo's settings to see the current save folder.

### The application says "Connection refused"
- This simply means the server hosting the file is temporarily unavailable or blocked by your firewall. Wait a few minutes and try again.
